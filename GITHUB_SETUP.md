# 🐙 Как настроить GitHub и сохранить проект

Это пошаговая инструкция, как загрузить ваш проект на GitHub и начать вести историю изменений.

## Шаг 1: Подготовка (Я уже сделал это за вас)
Я создал файл `.gitignore`, чтобы в интернет не улетели ваши пароли (`.env`) и мусорные файлы.

## Шаг 2: Создание репозитория на GitHub
1.  Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2.  Нажмите **"+"** в правом верхнем углу -> **New repository**.
3.  **Repository name**: Назовите его, например `karusel-bot`.
4.  **Privacy**: Выберите **Private** (чтобы никто не украл код) или **Public** (если хотите показать всем).
5.  **НЕ ставьте галочки** (Add README, .gitignore) — у нас это уже есть.
6.  Нажмите **Create repository**.

## Шаг 3: Запуск Git на компьютере
Откройте терминал в папке проекта (или используйте терминал в VS Code) и введите команды по очереди:

1.  **Инициализация** (превращаем папку в репозиторий):
    ```bash
    git init
    ```

2.  **Добавление файлов** (готовим их к сохранению):
    ```bash
    git add .
    ```

3.  **Первое сохранение** (коммит):
    ```bash
    git commit -m "Initial commit: Bot start"
    ```

4.  **Переименование ветки** (стандарт сейчас `main`):
    ```bash
    git branch -M main
    ```

5.  **Связка с GitHub** (замените ссылку на вашу!):
    *Скопируйте эту команду со страницы созданного репозитория на GitHub (раздел "...or push an existing repository from the command line")*
    ```bash
    git remote add origin https://github.com/ВАШ_НИК/karusel-bot.git
    ```

6.  **Отправка в интернет**:
    ```bash
    git push -u origin main
    ```

## 🔄 Как работать дальше (Повседневные команды)

Когда вы что-то изменили в коде и хотите сохранить:

1.  **Проверить, что изменилось**:
    ```bash
    git status
    ```
2.  **Добавить изменения**:
    ```bash
    git add .
    ```
3.  **Сохранить (закоммитить)**:
    ```bash
    git commit -m "Написал, что именно изменил"
    ```
4.  **Отправить на GitHub**:
    ```bash
    git push
    ```
